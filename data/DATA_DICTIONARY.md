# Data dictionary — used_cars.csv

Synthetic used-car listings for an Indian marketplace, generated by `generate_data.py` (seed 42). 6,000 unique listings
plus 80 duplicated rows added on purpose (6,080 rows in the file). Prices are as of 2025 (`DATA_YEAR`).
Licence: created for this course; free to use and share.

| Column | Type | Description | Values / range | Missing |
|---|---|---|---|---|
| `car_id` | integer | Listing identifier. Not a feature. | 1–6000 | none |
| `brand` | category | Car maker | Maruti, Hyundai, Tata, Mahindra, Honda, Toyota, Kia, Renault, Skoda | none |
| `model_segment` | category | Body type | Hatchback, Sedan, SUV | none |

## How prices were generated

```
new price  = segment base (Hatchback 6, Sedan 10, SUV 14 lakh) × brand factor × engine-size factor × fuel factor
used price = new price × 0.88 (drop when it leaves the showroom)
             × (share of value kept per year) ^ age        (Toyota and Maruti keep value best, Renault worst)
             × kilometre factor (more km than ~10,000 per year → cheaper)
             × 0.94 per extra owner × 1.07 automatic × 1.05 dealer × city factor
             × 0.70 if the car is a diesel at least 10 years old listed in Delhi
             × random noise of about ±9%
```

Knowing this lets you check whether a model learned sensible patterns, for example that price falls with age, or that an
old diesel in Delhi is cheaper than the same car in Chennai.

## Cleaning done in the notebook

- Drop the 80 duplicated rows (before the train/test split).
- Map "Bangalore" to "Bengaluru".
- Drop the 12 rows with `km_driven` above 5,00,000 km.
- Missing values are filled inside the model pipeline (median / most frequent value learned from the training data),
  with an extra 0/1 column that marks where mileage or engine size was missing.
